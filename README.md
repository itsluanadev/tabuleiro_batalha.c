# Tabuleiro de Batalha em C

Simulação de um tabuleiro de batalha naval em C, com o tabuleiro representado por matriz e navios posicionados no jogo.

## Tecnologias

- Linguagem C

## Como executar

1. Instale um compilador C (por exemplo, GCC).
2. Compile: `gcc tabuleiro_batalha.c -o tabuleiro_batalha`
3. Execute: `./tabuleiro_batalha`

## Funcionalidades

- Criação e exibição do tabuleiro 
- Posicionamento de navios 
- Regras de ataque e resultado 

## O que aprendi

- Matrizes (vetores bidimensionais)
- Laços de repetição aninhados
- Validação de posições e limites
